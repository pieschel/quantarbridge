# QuantarBridge v0.1.0

This first public release synchronizes the validated production bridge fixes
and adds a reproducible Raspberry Pi ARM64 distribution.

## Highlights

- BrandMeister Defined Short Data reassembly and UTF-16BE routing for weather
  and text replies.
- Automatic BREW session recovery when the server rejects the group-idle
  message for an owned uplink call.
- Flashable Raspberry Pi OS Lite 64-bit image with native ARM64 builds of
  QuantarBridge, the pinned DVMHost stack, and `tetra-codec`.
- Secure `quantarbridge-setup` first-run configuration without embedded
  station credentials or private runtime state.
- Regression tests for the live messaging and voice-recovery paths.

## Raspberry Pi image

Download the `.img.xz` release asset and verify it with the accompanying
`.sha256` file. In Raspberry Pi Imager choose **Use custom**, configure a
unique administrator login and SSH access, write the card, then run:

```bash
sudo quantarbridge-setup
```

The same image is published as an OCI package:

```bash
oras pull ghcr.io/pieschel/quantarbridge-rpi-image:v0.1.0
```

The image targets the Motorola Quantar V.24/DFSI topology. It is not an
MMDVM_HS GPIO-Hat image.

## Validation

- QuantarBridge, DVMHost, and `tetra-codec` verified as `ARM aarch64`.
- ARM image test suite: 15/15 passed.
- Full repository CI, public-tree audit, ShellCheck, configuration generation,
  x86 build, and tests passed.
