# QuantarBridge v0.1.2

This release fixes the initial SSH login in the Raspberry Pi ARM64 image.

## Fixed

- Provision the public `qbadmin` account through Raspberry Pi OS's supported
  `userconf-pi` mechanism instead of creating a competing additional user.
- Complete and disable the Raspberry Pi first-boot user wizard during the
  image build.
- Remove the SSH banner that reported an unfinished user configuration.
- Keep the initial password active long enough for the first SSH login.
- Perform a real password-based SSH login against the completed ARM64 root
  filesystem during every image build.

## Initial login

```text
Username: qbadmin
Password: quantarbridge
```

Connect over a trusted Ethernet network:

```bash
ssh qbadmin@raspberrypi.local
passwd
sudo quantarbridge-setup
```

The initial password is intentionally public. Change it immediately with
`passwd` before exposing the Pi to any untrusted network.

## Image and package

The flashable `.img.xz`, checksum, build metadata, and ARM64 architecture
report are attached to this release. The OCI artifact is available with:

```bash
oras pull ghcr.io/pieschel/quantarbridge-rpi-image:v0.1.2
```

## Validation

- Native ARM64 builds of QuantarBridge, DVMHost, and `tetra-codec`.
- Raspberry Pi first-boot user configuration is disabled and its SSH banner is
  absent.
- Real SSH password authentication as `qbadmin` succeeds inside the built
  ARM64 root filesystem.
- ARM image test suite: 15/15 passed.
- Full repository CI and public-tree audit passed.
