# QuantarBridge v0.1.1

This release rebuilds the Raspberry Pi ARM64 image with a documented bootstrap
login for installations where Raspberry Pi Imager does not offer OS
customisation for the downloaded image.

## Initial login

```text
Username: qbadmin
Password: quantarbridge
```

The password is expired in the image. SSH requires it to be replaced during
the first login before the account can be used normally. Keep the Pi on a
trusted local network until that password change is complete.

After login, configure the bridge with:

```bash
sudo quantarbridge-setup
```

## Image and package

The flashable `.img.xz`, checksum, build metadata, and ARM64 architecture
report are attached to this release. The same image is available as an OCI
artifact:

```bash
oras pull ghcr.io/pieschel/quantarbridge-rpi-image:v0.1.1
```
