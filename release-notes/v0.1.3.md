# QuantarBridge v0.1.3

This release makes direct BrandMeister voice and packet data the default for
the Motorola Quantar V.24/DFSI topology and refreshes the Raspberry Pi ARM64
image accordingly.

## Direct BrandMeister default

- Enable native BrandMeister group voice in the generated runtime.
- Restore the P25-to-DMR and DMR-to-P25 transcoder roles and their validated
  gain baselines.
- Keep TETRAPACK BREW available only as an explicit opt-in migration.
- Route configured messaging services through native BrandMeister packet data
  while retaining the reply route to the requesting APX.
- Restart the direct voice components when static BrandMeister routing changes.

## Raspberry Pi image

- Remove the mandatory BREW username from first-time setup.
- Leave the BREW audio worker disabled in a fresh image.
- Present direct voice, TMS, and LRRP services in the dashboard and image
  documentation.

## Validation

- Native ARM64/aarch64 compilation on Raspberry Pi 5.
- 16/16 CTest targets passed on ARM64.
- 96/96 Python unit tests passed.
- Public-tree and shell-script audits passed.
- Live bidirectional Quantar voice was confirmed before packaging.
