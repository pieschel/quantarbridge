# QuantarBridge v0.1.6

Released 23 November 2026.

This release packages the corrected bidirectional direct converters, the
accepted audio tuning and automatic incoming DMR-to-P25 level adjustment.
It also corrects the dashboard's health summary for direct BrandMeister
installations.

## Direct audio

- P25 to DMR corrects gain quantization, spectral bit packing and silence
  handling while retaining the codec's spectral state.
- DMR to P25 corrects source-model mapping and stream-state handling.
- The incoming DMR leveler adapts to differences between stations using
  speech/noise confidence, bounded gain changes and peak protection. It does
  not raise gain during non-speech. The shipped target is `-29.5`, with maximum
  boost `12 dB` and normal maximum cut `18 dB`; an emergency peak guard can
  reduce exceptionally strong input further.
- The accepted fixed gain, spectral scale and disabled optional de-essers are
  retained. See the [operations guide](../docs/OPERATIONS.md) for the exact
  settings and the distinction between direct and legacy PCM controls.

The changes improve conversion and loudness consistency; they do not remove
distortion already present at the source or guarantee artifact-free sound
from every station.

## Dashboard

The direct BrandMeister profile monitors DVMHost, DVMFNE, both converter
directions and QuantarBridge. The unused DMR Gateway is not a dependency of
that profile, so its absence does not produce a restricted-system warning.
An actual failure of a configured required service still degrades health.

When recent BrandMeister logs contain no connection event, dashboard startup
can restore the latest valid timestamped event from older logs. Its original
timestamp is retained. Historical calls and talkgroup subscriptions are not
replayed, and a running service alone is not treated as proof of connection.

## Raspberry Pi image and installation

The ARM64 image builds the stack from the pinned upstream sources and this
release's patches. Build assets include the flashable `.img.xz`, its SHA-256,
revision information, architecture checks, SSH/sudo authentication checks and
configuration-persistence results after filesystem unmount/remount. The
configuration-parser and persistence fixes from v0.1.5 are retained.

This is a reusable installation image, not a copy of the private live station
or its backup. It contains no production credentials, radio recordings or
runtime activity. Initial SSH login remains `qbadmin` / `quantarbridge`;
change the password immediately, then run `sudo quantarbridge-setup` with
the assigned station values. Flashing replaces the SD card contents, so keep
an existing installation's private backup separately.

The corresponding audio settings were assessed on the running Quantar
system. The newly packaged image has not been physically boot-tested on a
Raspberry Pi. Automated checks do not replace target-hardware startup and
bidirectional RF/packet-data validation after setup.

## Existing installations

Install the matching DVMHost patch and converter configuration together.
The new `directP25ToAmbe` and `directAmbeToP25` settings replace the older
direct-converter flags; adding them to an old binary is insufficient.
Preserve station-specific passwords, identities, frequencies, mappings and
service choices. Do not replace a private runtime file with a public example
or rerun setup with guessed values. Restart affected services only during
an idle period after making a private backup.
